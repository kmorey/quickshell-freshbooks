# Map Omarchy 4's Quickshell extension seams

## Question

How should an installable plugin integrate with Omarchy 4 and Quickshell, and which official or first-party calendar/clock, popup, process, state, theming, keyboard, packaging, and distribution conventions should this project follow?

## Blocked by

- None

## Resolution

Resolved in [Omarchy 4 Quickshell extension seams](../../docs/research/omarchy4-quickshell-extension-seams.md): use a root-manifest `service` + `bar-widget` plugin, with one service owning CLI/state/synchronization and a clock-shaped keyboard popup that expands into calendar/history. The report maps process, persistence, theme, keyboard, packaging, versioning, and distribution seams, and explicitly separates documented APIs from first-party source conventions. Branch capture was unavailable because this folder is not a Git repository.
