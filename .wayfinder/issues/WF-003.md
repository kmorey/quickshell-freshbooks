# Audit freshbooks-cli's time-tracking surface

## Question

Which project, client, time-entry, and timer operations does `freshbooks-cli` currently expose; what output/error/authentication contracts does it offer for a Quickshell consumer; and what concrete gaps would need CLI changes?

## Blocked by

- None

## Resolution

The [`freshbooks-cli` time-tracking surface audit](../../docs/research/freshbooks-cli-time-tracking.md) records the released commands, JSON/exit/auth contracts, and exact plugin gaps. Version 0.1.0 is a strong CLI-only baseline but still needs normalized client/project/entry schemas, verified pause/resume and Duration Correction, safe Timer Switch reporting, remote-change detection, and bounded process/history contracts. Research was written directly into this folder because it is not a Git repository, so branch capture was unavailable.
